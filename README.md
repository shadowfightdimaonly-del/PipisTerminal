# PipisTerminal

Мобильная среда для запуска Python-кода на Android в стиле Pipis.

## Текущие возможности

- встроенный Python runtime через `serious_python`;
- редактор Python-кода;
- запуск кода кнопкой;
- вывод `stdout` и `stderr`, включая traceback ошибок;
- открытие и сохранение обычных `.py` файлов;
- «Сохранить как»;
- отображение имени файла и несохранённых изменений;
- аргументы командной строки с поддержкой кавычек, например `hello "hello world"`;
- выбор рабочей папки проекта;
- передача пути скрипта в `__file__`;
- выполнение `sys.argv` с именем скрипта и аргументами;
- запуск с выбранной рабочей папкой, чтобы относительные пути вроде `open("data.txt")` использовали её;
- последовательное выполнение запросов Python, чтобы глобальные `sys.argv`, stdout/stderr и текущая директория не пересекались между запусками;
- чёрный интерфейс с фиолетовым акцентом.

Python запускается локально на устройстве. Для выполнения кода не нужен удалённый сервер.

## Интеграция с PipisEdit

PipisTerminal открывает и сохраняет обычные `.py` файлы. Поэтому один и тот же файл можно редактировать в PipisEdit и запускать в PipisTerminal. Если скрипт использует другие файлы проекта, выбери папку проекта кнопкой с иконкой папки.

## Известные ограничения

- Рабочая папка должна быть доступна Python runtime как обычный путь файловой системы Android. Если системный picker возвращает путь, недоступный runtime, чтение файлов может не сработать.
- Аргументы разбираются по правилам `shlex`; это не полноценная оболочка и команды терминала Android не запускаются.
- Программы с длительным интерактивным вводом пока не поддерживаются как полноценная терминальная сессия.
- Выбор папки не создаёт отдельный файловый менеджер проекта.
