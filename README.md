# PipisTerminal

Мобильная среда для запуска Python-кода на Android в стиле Pipis.

## v0.2

Теперь PipisTerminal умеет работать с обычными `.py` файлами:

- встроенный Python runtime;
- редактор Python-кода;
- запуск кода кнопкой;
- вывод stdout/stderr;
- отображение ошибок Python;
- открытие `.py` через системный файловый picker;
- сохранение открытого файла;
- «Сохранить как»;
- отображение текущего файла и состояния несохранённых изменений;
- чёрный интерфейс с фиолетовым акцентом.

Python запускается локально на устройстве через `serious_python`, без удалённого сервера.

## PipisEdit

Это первый этап интеграции с PipisEdit: PipisTerminal теперь может открыть и сохранить тот же обычный `.py` файл, который редактируется в PipisEdit. Отдельный файловый менеджер на этом этапе не нужен.
