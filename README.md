# PipisTerminal

Мобильная среда для запуска Python-кода на Android в стиле Pipis.

## v0.1

Первая версия делает только самое необходимое:

- встроенный Python runtime;
- редактор Python-кода;
- запуск кода кнопкой;
- вывод stdout/stderr;
- отображение ошибок Python;
- чёрный интерфейс с фиолетовым акцентом.

Python запускается локально на устройстве через `serious_python`, без удалённого сервера.

## Дальше

Планируется добавить сохранение `.py` файлов, проекты, вкладки, файловую навигацию, аргументы командной строки, историю запусков и интеграцию с PipisEdit.

Проект на ранней стадии разработки. Не считать его полноценной заменой IDE до появления файлового менеджера и устойчивого запуска долгих программ.
